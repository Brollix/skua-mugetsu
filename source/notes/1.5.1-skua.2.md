**The game player bundled with [Bonxie](https://github.com/retr0gr4d3/Bonxie).** Bonxie downloads this release by itself; you don't need to install it separately.

## Skua build 1.5.1-skua.2
- Linux: the game draws inside Bonxie's window (`--skua-parent` with an X11 window), and clicking it gives it the keyboard like on Windows. No changes on Windows.

Mugetsu 1.5.1 plus `source/patches/skua.patch`:
- `--skua-bridge host:port`: connects to Bonxie, which can then call skua.swf's ExternalInterface callbacks and receives its events. The player exits when Bonxie closes the connection.
- `--skua-parent <window handle>`: draws inside Bonxie's window (a Win32 or X11 window) instead of its own.
- No update check when started by Bonxie (Bonxie pins the player version).

Without those options it behaves like Mugetsu 1.5.1.
