## New in 1.6.0
**macOS version**
Mugetsu now comes for macOS too (one app for Apple Silicon and Intel), built by the same GitHub workflow from the same source. This is its first release, so please report anything that doesn't work. Thanks to lazuee for the macOS build.

**No more freezes when entering a room**
Entering a busy room used to freeze the game for a moment (up to about a fifth of a second) while every new armor, weapon and pet was prepared for drawing at once. That work now runs on all processor cores in the background while the game keeps going; anything not ready yet appears a frame or two later.

**Much less memory**
- Shapes take about half the memory on the graphics card.
- Gear that several players wear, and the game code inside every item, is now shared instead of kept once per copy. In a test loading 1,251 AQW items three times each, memory went from 5.4 GB to 1.8 GB, and loading got faster.
- Spare graphics memory is released sooner, and shapes not drawn for 10 minutes are freed. In a boss fight Mugetsu used about 1 GB less than 1.5.1.
- On Linux and macOS, Mugetsu now watches the graphics card's memory and frees spare memory when it runs low, as on Windows. Thanks to JonasAlv.

**Fixes**
- Map music could come back at full volume after turning it off and on, changing rooms or closing a cutscene. Fixed.
- With Flash-style edge smoothing, a thin line could appear around some details drawn on top of each other (for example the eye on the Cleaver of Madness). Fixed.
- With frame interpolation, the picture rate now comes back up within about a second after a room has loaded, instead of staying at 30 for several seconds.
