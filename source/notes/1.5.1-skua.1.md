**The game player bundled with [VibeSkua](https://github.com/retr0gr4d3/VibeSkua).** VibeSkua downloads this release by itself; you don't need to install it separately.

## Skua build 1.5.1-skua.1
Mugetsu 1.5.1 plus `source/patches/skua.patch`:
- `--skua-bridge host:port`: connects to VibeSkua, which can then call skua.swf's ExternalInterface callbacks and receives its events. The player exits when VibeSkua closes the connection.
- `--skua-parent <window handle>`: draws inside VibeSkua's window instead of its own.
- No update check when started by VibeSkua (VibeSkua pins the player version).

Without those options it behaves like Mugetsu 1.5.1.
